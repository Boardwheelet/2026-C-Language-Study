# 1087번 - Kram 17인치 구매 대작전

- **사이트** : ASCODE
- **분류** : 반복문
- **제한** : 시간 1초 / 메모리 128MB
- **링크** : http://ascode.org/problem.php?id=1087

---

## 📝 문제 설명

월요일부터 시작해 하루도 쉬지 않고 알바할 때, 목표 금액을 모으려면 **몇 일** 일해야 하는가?

| 요일 | 시급 | 최대 시간 | 하루 수입 |
|------|------|-----------|-----------|
| 월~목 | 9,000원 | 4시간 | **36,000원** |
| 금~일 | 10,000원 | 6시간 | **60,000원** |

---

## 📥 입력

```
첫 줄: 테스트케이스 수 T (1 ≤ T ≤ 10)
다음 T줄: 목표 금액 n
```

## 📤 출력

```
목표 금액을 달성하는 데 필요한 최소 일수 출력
```

---

## 💡 예제

| 입력 | 출력 |
|------|------|
| 1000000 | 22 |
| 1500000 | 33 |

---

## 🧠 풀이 핵심

- j=1이 월요일 → **7일 주기**로 판별
- 금(j%7==5), 토(j%7==6), 일(j%7==0) → 60,000원
- 나머지(월~목) → 36,000원

| j | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | ... |
|---|---|---|---|---|---|---|---|---|-----|
| 요일 | 월 | 화 | 수 | 목 | **금** | **토** | **일** | 월 | ... |
| j%7 | 1 | 2 | 3 | 4 | **5** | **6** | **0** | 1 | ... |

```c
for (int j = 1; sum < price; j++) {
    if (j % 7 == 5 || j % 7 == 6 || j % 7 == 0)  // 금, 토, 일
        sum += 60000;
    else                                            // 월~목
        sum += 36000;
    count++;
}
```

---

## ✅ 내 코드

```c
#include <stdio.h>

int main() {
    int testcase;
    scanf("%d", &testcase);

    for (int i = 0; i < testcase; i++) {
        int price;
        scanf("%d", &price);

        int sum = 0;
        int count = 0;
        for (int j = 1; sum < price; j++) {
            if (j % 7 == 5 || j % 7 == 6 || j % 7 == 0)  // 금, 토, 일
                sum += 60000;
            else                                            // 월~목
                sum += 36000;
            count++;
        }

        printf("%d\n", count);
    }

    return 0;
}
```

## ⚠️ 주의 / 실수 포인트

- 1204번과 달리 **금요일도 고수입 그룹**에 포함 → 조건이 3개 (`j%7 == 5, 6, 0`)
- j=1을 월요일로 고정했을 때 금=5, 토=6, 일=0 으로 매핑되는 것 확인 필수
