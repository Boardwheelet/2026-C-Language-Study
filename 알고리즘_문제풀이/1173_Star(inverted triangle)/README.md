# 1173번 - 역삼각형 그리기

## 📋 문제 정보

- **사이트** : ASCODE
- **분류** : 반복문 / 별찍기
- **제한** : 시간 1초 / 메모리 128MB
- **링크** : http://ascode.org/problem.php?id=1173

---

## 📝 문제 설명

높이 n이 주어지면, 첫 줄은 `A`를 n개, 다음 줄은 `B`를 n-1개, ... 마지막 줄은 해당 알파벳 1개를 출력하는 역삼각형을 그린다.

---

## 📥 입력

```
첫 줄: 테스트케이스 수 T (1 ≤ T ≤ 10)
다음 T줄: 역삼각형 높이 n
```

## 📤 출력

```
A부터 시작해 줄마다 알파벳 순서로 별 개수를 1씩 줄여가며 출력
테스트케이스 사이에 빈 줄 한 칸 삽입
```

---

## 💡 예제

**입력**
```
2
4
7
```

**출력**
```
AAAA
BBB
CC
D

AAAAAAA
BBBBBB
CCCCC
DDDD
EEE
FF
G

```

## 🧠 풀이 핵심

| 줄(j) | 알파벳 | 개수 |
|-------|--------|------|
| 1번째 | `A` (= 'A' + 0) | `n` |
| 2번째 | `B` (= 'A' + 1) | `n - 1` |
| j번째 | `'A' + (j-1)` | `n - (j-1)` |

1. j를 1부터 n까지 반복
2. 알파벳: `'A' + (j-1)` → j가 1이면 A, 2면 B ...
3. 개수: `n - (j-1)` → j가 1이면 n개, 마지막이면 1개
4. **테스트케이스 사이 빈 줄** → 마지막 케이스 이후에도 빈 줄 출력됨 (예제 참고)

```c
for (int i = 0; i < T; i++) {
    int n;
    scanf("%d", &n);

    for (int j = 1; j <= n; j++) {
        char ch = 'A' + (j - 1);
        int count = n - (j - 1);
        for (int k = 0; k < count; k++) {
            printf("%c", ch);
        }
        printf("\n");
    }
    printf("\n"); // 테스트케이스 사이 빈 줄 (마지막 포함)
}
```

## ✅ 내 코드

```c
#include <stdio.h>

int main() {
    int test_case;
    scanf("%d", &test_case);

    for (int i = 0; i < test_case; i++) {
        int size;
        scanf("%d", &size);

        int alph = 0;
        for (int j = size; j > 0; j--) { // 가로 길이 = j, 알파벳은 alph로 별도 관리
            for (int k = 0; k < j; k++) {
                printf("%c", 65 + alph);  // 65 = 'A'
            }
            alph++;
            printf("\n");
        }
        printf("\n"); // 테스트케이스 사이 빈 줄
    }

    return 0;
}
```

> **핵심 아이디어:** j는 출력 개수(size → 1 감소), alph는 알파벳 인덱스(0 → 증가) — 두 변수를 **분리**해서 관리

---

## ⚠️ 주의 / 실수 포인트

- 빈 줄은 **마지막 테스트케이스 이후에도** 출력됨 → `if (i < T-1)` 조건 없이 그냥 `printf("\n")` 해도 정답
- 알파벳 계산 시 `'A' + j` 하면 B부터 시작하는 실수 → 반드시 `'A' + (j-1)`
