- **사이트** : ASCODE
- **분류** : 반복문

---

## 📝 문제 설명

월요일부터 시작해 하루도 쉬지 않고 알바할 때, 목표 금액을 모으려면 **몇 일** 일해야 하는가?

| 요일 | 시급 | 최대 시간 | 하루 수입 |
|------|------|-----------|-----------|
| 월~금 | 8,000원 | 5시간 | **40,000원** |
| 토~일 | 10,000원 | 8시간 | **80,000원** |

---

## 📥 입력

```
첫 줄: 테스트케이스 수 T (1 ≤ T ≤ 10)
다음 T줄: 목표 금액 n (1,000,000 ≤ n ≤ 2,500,000)
```

## 📤 출력

```
목표 금액을 달성하는 데 필요한 최소 일수 출력
```

---

## 💡 예제

| 입력 | 출력 |
|------|------|
| 1000000 | 20 |
| 1500000 | 30 |

---

## 🧠 풀이 핵심

- j=1이 월요일 → **7일 주기**로 판별
- 토(j=6), 일(j=7) → `j % 7 == 6 || j % 7 == 0` → 80,000원
- 누적합 `sum >= price` 되는 순간의 `count` 출력

```c
for (int j = 1; sum < price; j++) {
    if (j % 7 == 6 || j % 7 == 0)  // 토, 일
        sum += 80000;
    else                             // 월~금
        sum += 40000;
    count++;
}
```

## ✅ 내 코드 (수정본)

```c
#include <stdio.h>

int main() {
    int testcase;
    scanf("%d", &testcase);

    for (int i = 0; i < testcase; i++) {
        int price;
        scanf("%d", &price);

        int sum = 0;
        int count = 0;
        for (int j = 1; sum < price; j++) {
            if (j % 7 == 6 || j % 7 == 0)  // 토, 일
                sum += 80000;
            else
                sum += 40000;
            count++;
        }

        printf("%d\n", count);
    }

    return 0;
}
```

## ⚠️ 핵심 실수 포인트

> ❌ `j % 6 == 0 || j % 7 == 0`  
> ✅ `j % 7 == 6 || j % 7 == 0`

주말(토·일) 자체를 묶는 방향은 맞지만, **7일 주기**로 판별해야 함!

| j | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | ... | 13 | 14 |
|---|---|---|---|---|---|---|---|---|-----|----|----|
| 요일 | 월 | 화 | 수 | 목 | 금 | **토** | **일** | 월 | ... | **토** | **일** |
| j%7 | 1 | 2 | 3 | 4 | 5 | **6** | **0** | 1 | ... | **6** | **0** |
| j%6 | 1 | 2 | 3 | 4 | 5 | **0** | 1 | 2 | ... | 1 | 2 |

→ `j % 6 == 0`은 6, 12, 18...번째 날을 잡는데, **12번째 날은 토요일이 아님!**
