# 1443번 - (3n+1) 문제 #3

## 📋 문제 정보

- **사이트** : ASCODE
- **분류** : 반복문
- **제한** : 시간 1초 / 메모리 128MB
- **링크** : http://ascode.org/problem.php?id=1443

---

## 📝 문제 설명

양의 정수 n에 대해 아래 규칙을 반복한다.

- n이 **홀수**면 → `3 * n + 1`
- n이 **짝수**면 → `n / 2`
- 결과가 **1이 될 때까지** 반복

이때 n부터 1까지 생성된 수열의 **항의 개수**를 m이라 한다.

---

## 📥 입력

```
첫 줄: 테스트케이스 수 t (1 ≤ t ≤ 10)
다음 t줄: 양의 정수 a, b (1 ≤ a, b ≤ 100,000)
```

## 📤 출력

```
a 이상 b 이하 정수 중 수열 길이 m이 최대인 최솟값 n과 m을 출력
```

---

## 💡 예제

| 입력 | 출력 |
|------|------|
| 1 10 | 9 20 |
| 100 200 | 171 125 |

---

## 🧠 풀이 핵심

1. a, b 중 작은 값부터 큰 값까지 반복
2. 각 n마다 3n+1 수열 길이 계산
3. 최대 길이 갱신 시 n과 m 저장 (같은 길이면 더 작은 n 유지 → `>` 조건)
